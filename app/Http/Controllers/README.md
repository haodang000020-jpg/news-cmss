# Controllers

Namespace: `App\Http\Controllers`

Quy uoc:
- Controller chi nhan request, goi Service/Action va tra response.
- Controller admin dat trong `App\Http\Controllers\Admin`.
- Controller frontend dat trong `App\Http\Controllers\Frontend`.
- Ten controller: `{Entity}Controller` hoac `{Feature}Controller`.

Vi du:
- `App\Http\Controllers\Admin\ArticleController`
- `App\Http\Controllers\Frontend\HomeController`
